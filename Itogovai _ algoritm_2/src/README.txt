Практическая работа Java «Сеть между корпусами»

Структура:
- Main.java — главный класс, запуск программы
- Edge.java — класс ребра графа
- GraphData.java — исходные данные графов
- Dijkstra.java — алгоритм Дейкстры
- BellmanFord.java — алгоритм Беллмана — Форда
- FloydWarshall.java — алгоритм Флойда — Уоршелла
- Prim.java — алгоритм Прима
- Kruskal.java — алгоритм Краскала
- DisjointSet.java — структура непересекающихся множеств для Краскала
- MSTChecker.java — проверка минимального остовного дерева

Все классы находятся в отдельных файлах. Вложенных классов нет.

Запуск:
1. Открой папку проекта в IntelliJ IDEA.
2. Убедись, что папка src помечена как Sources Root (если IDEA не сделала это автоматически).
3. Открой Main.java.
4. Нажми Run.

Пакет не используется, поэтому файлы можно запускать без настройки package.
Требуется JDK 8 или новее.
